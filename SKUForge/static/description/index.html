SKUFORGE – Advanced SKU Generator

Forge Your SKU, Perfect Your Inventory

Overview

SKUFORGE is a powerful, enterprise-grade SKU generation solution designed to automatically create unique, consistent, and meaningful SKU codes for products and product variants. With its intuitive pattern builder and flexible configuration options, SKUFORGE eliminates manual SKU entry errors and streamlines your inventory management process.

Whether you're managing a small catalog or thousands of products, SKUFORGE adapts to your business rules and automatically generates SKUs that follow your exact specifications.

🎯 Key Advantages

⚡ Time-Saving Automation

Eliminate hours of manual SKU entry. SKUs are generated automatically when products are created, saving valuable time and reducing human error.

🎨 Flexible Pattern Builder

Create custom SKU patterns using drag-and-drop components. Mix and match product names, categories, attributes, dates, sequences, and more.

✅ Uniqueness Validation

Built-in validation ensures every SKU is unique across your entire product catalog, preventing duplicate codes and data conflicts.

🔄 Bulk Generation

Generate SKUs for existing products in bulk using the intuitive wizard. Choose to override existing SKUs or only fill empty ones.

🎯 Variant Support

Intelligent handling of product variants with attribute-based SKU components. Each variant gets a unique, meaningful SKU code.

🛡️ Manual Override Protection

Respects manually entered SKUs. Your custom codes are never overwritten unless you explicitly choose to regenerate them.

✨ Key Features

  • SKU Pattern Builder UI: Intuitive drag-and-drop interface for creating complex SKU patterns
  • Pattern Components:
    • Product Name: Extract first N characters (with uppercase/lowercase options)
    • Category: Use category name or abbreviation
    • Attributes: Include variant attributes (Color, Size, etc.)
    • Date: Multiple formats (YYYY, YYMM, YYMMDD, etc.)
    • Sequence: Auto-incrementing numbers with customizable padding
    • Company: Company code or name abbreviation
    • Fixed Text: Custom prefixes, suffixes, or separators
  • Automatic Generation: SKUs generated automatically on product creation
  • Bulk Generation Wizard: Generate SKUs for multiple products at once
  • Uniqueness Validation: Prevents duplicate SKUs across all products
  • Case Transformation: Convert text to uppercase, lowercase, or keep original
  • Custom Separators: Add separators between pattern components

🚀 How to Use SKUFORGE

Step 1: Installation

  1. Install the SKUFORGE module from the Odoo Apps
  2. Wait for the installation to complete
  3. The module will be available in your Inventory menu

Step 2: Create Your First SKU Pattern

  1. Navigate to Inventory → Configuration → SKU Configurations
  2. Click Create to add a new pattern
  3. Enter a descriptive name for your pattern (e.g., "Standard Product SKU")
  4. In the Components tab, add pattern components:
    • Click Add a line to add components
    • Select the component type (Fixed Text, Product Name, Category, etc.)
    • Configure each component's settings (length, case, format, etc.)
    • Use the drag handle to reorder components
    • Add separators between components if needed
  5. Check Default Pattern to make it the default for new products
  6. Click Save

Step 3: Example Pattern Configuration

Here's an example of a common SKU pattern:

Pattern: PROD-ABC-001
Components:
1. Fixed Text: "PROD-"
2. Product Name: First 3 characters (Uppercase)
3. Separator: "-"
4. Sequence: 3-digit padding (001, 002, 003...)

Step 4: Automatic SKU Generation

  1. Create a new product in Inventory → Products → Products
  2. Leave the Internal Reference (SKU) field empty
  3. Fill in other product details (name, category, etc.)
  4. Click Save
  5. The SKU will be automatically generated based on your default pattern!

Step 5: Bulk Generate SKUs for Existing Products

  1. Go to Inventory → Products → Products
  2. Select multiple products from the list view
  3. Click Action → Generate SKU
  4. In the wizard:
    • Choose whether to override existing SKUs or only fill empty ones
    • Click Generate
  5. SKUs will be generated for all selected products

Step 6: Manual SKU Override

If you need to manually set a SKU for a specific product:

  1. Open the product form
  2. Enter your custom SKU in the Internal Reference field
  3. Save the product
  4. Your manual SKU will be preserved and never overwritten automatically

💡 Use Cases & Examples

Example 1: Simple Product SKU

Pattern: Category (3 chars) + Product Name (3 chars) + Sequence (4 digits)

Result: ELE-LAP-0001, ELE-PHO-0002, CLT-SHI-0003

Example 2: Date-Based SKU

Pattern: Year + Month + Category (2 chars) + Sequence (3 digits)

Result: 202412-EL-001, 202412-EL-002

Example 3: Variant SKU with Attributes

Pattern: Product Name (3 chars) + Color Attribute + Size Attribute + Sequence

Result: TSH-RED-M-001, TSH-BLU-L-002

Example 4: Company-Specific SKU

Pattern: Company Code (3 chars) + Category (2 chars) + Year + Sequence

Result: ABC-EL-2024-001

✅ Best Practices

  • Plan Your Pattern: Think about your SKU structure before creating patterns. Consider future scalability.
  • Use Sequences: Always include a sequence component to ensure uniqueness, especially for products with similar names.
  • Keep It Short: Shorter SKUs are easier to manage, but ensure they remain meaningful.
  • Test Patterns: Create test products to verify your pattern generates the expected SKU format.
  • Document Patterns: Use descriptive names for patterns to remember their purpose.
  • Backup Before Bulk Generation: Always backup your database before running bulk SKU generation on large product sets.
