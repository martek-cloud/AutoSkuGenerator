Why SKUFORGE?

SKUFORGE helps businesses eliminate manual SKU creation by automatically generating structured, unique, and meaningful SKU codes for products and variants.

Define your SKU logic once and let Odoo generate consistent product codes across your entire catalog, from small inventories to enterprise-scale product ranges.

Key Benefits

  • Time saving: Automatic SKU generation on product creation
  • Consistency: Enforce company-wide SKU standards
  • Uniqueness: Built-in validation prevents duplicate SKUs
  • Flexibility: Fully configurable SKU patterns
  • Variant ready: Intelligent SKU logic for product variants
  • Manual safe: Manually entered SKUs are never overwritten

Main Features

  • Configurable SKU pattern builder
  • Automatic SKU generation on product creation
  • Bulk SKU generation wizard for existing products
  • Attribute-based SKU generation for product variants
  • Custom formatting: case, separators, and padding

Available SKU Components

  • Product name (first N characters)
  • Product category
  • Variant attributes (color, size, etc.)
  • Date components (year, month, day)
  • Automatic sequence with custom padding
  • Company code
  • Fixed text (prefixes and suffixes)

Real-World Examples

Electronics:
ELE-LAP-0001, ELE-PHO-0002

Date-based:
2024-EL-001, 2024-EL-002

Variants:
TSH-RED-M-001, TSH-BLU-L-002

Multi-company:
ABC-EL-2024-001

How It Works

  1. Install the module
  2. Create your SKU pattern in Inventory → Configuration → SKU Configurations
  3. Set a default pattern
  4. Create products and variants
  5. SKUs are generated automatically
  6. Use the bulk wizard for existing products
